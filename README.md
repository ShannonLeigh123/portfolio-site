# Portfolio Website

A responsive, Bootstrap-based personal portfolio showcasing my design style, projects, and web development work. This site serves as the central hub for my online professional presence and bridges to my core web applications.

## 🚀 Live Website
Explore my live portfolio site here: **[Shannon | Portfolio](https://portfolio-site-437f.onrender.com)**

---

## ✨ Features
* **Responsive Architecture:** Fluid, edge-to-edge layout optimization engineered with Bootstrap 5.
* **Modern Aesthetic:** Clean UI emphasizing dark cosmic-inspired background styling and deep content contrast.
* **Modular Infrastructure:** Fully partitioned design containing specialized modules for About, Skills, Projects, and Contact sections.
* **Application Pipeline:** Direct production connection routes linking out to deployed live environments.

## 🛠️ Tech Stack
* **Frontend UI:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5
* **Infrastructure & DNS:** Cloudflare Network (Domain Routing & Security Overlays)
* **Production Deployment:** Render (Static Web Hosting Environment)

---

## 🔗 Integrated Ecosystem Projects
Both production web platforms featured within this portfolio showcase full database architectures:
* 🌌 **[GoodnessGaseous](https://github.com):** A Django-powered mini stellar encyclopedia cataloging astronomical data backends.
* 📝 **[NotableNotes](https://github.com):** A creative personal interest log web application mapping customizable user entries.

## 🌐 Deployment Configuration
This architecture runs as an automated continuous deployment static web container hosted via **Render**. Traffic routing passes through edge firewalls configured inside **Cloudflare** for optimization and DNS domain integration mapping.
