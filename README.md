# Portfolio Website

A responsive Bootstrap-based personal portfolio showcasing my design style, projects, and development work. This site serves as the main hub for my online presence and links to my two Django applications: GoodnessGaseous and NotableNotes.

## Features
- Fully responsive layout built with Bootstrap 5
- Clean, modern UI with cosmic-inspired color accents
- Sections for About, Skills, Projects, and Contact
- Direct links to my deployed Django projects
- Easy to update and maintain

## Deployment
This site is deployed as a Static Site using Render.  
Once deployed, it will be connected to my custom domain through Cloudflare.
